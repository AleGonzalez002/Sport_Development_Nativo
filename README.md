# 🏋️ Sport Development

**Plataforma de gestión y desarrollo para el sector deportivo.**

## 📋 ¿Qué es?
Sport Development es una aplicación web para gestionar órdenes, productos, reportes y seguimiento de clientes en negocios relacionados con el deporte y fitness. Incluye funcionalidades de pedidos, pagos, tracking y generación de reportes analíticos.

## 🛠️ Tecnologías
- **Backend**: PHP
- **Frontend**: HTML, CSS, JavaScript
- **Base de Datos**: MySQL
- **Servidor Local**: XAMPP
- **Email**: PHPMailer (envío de notificaciones)

## ⚙️ Activar en Local (XAMPP)

### Requisitos
- XAMPP instalado (incluye Apache, MySQL y PHP)

### Pasos
1. **Clonar el repositorio**: `git clone https://github.com/AleGonzalez002/Sport_Development_Nativo.git`
2. **Mover a XAMPP**: `mv Sport_Development_Nativo C:\xampp\htdocs\`
3. **Iniciar XAMPP**: Abre XAMPP Control Panel e inicia Apache y MySQL
4. **Crear Base de Datos**: Accede a `http://localhost/phpmyadmin` e importa el SQL
5. **Acceder**: `http://localhost/Sport_Development_Nativo`
